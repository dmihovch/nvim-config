# Cheatsheet

Leader key: `<Space>`

## Files

| Key | Action |
|---|---|
| `<leader>ff` | Find files |
| `<leader>fp` | Find files (git) |
| `<leader>f.` | Recent files |
| `<leader>e` | File explorer |

## Search

| Key | Action |
|---|---|
| `<leader>fg` | Live grep |
| `<leader>fw` | Grep word under cursor |
| `<leader>fh` | Help tags |
| `<leader>fk` | Keymaps |
| `<leader>fc` | Commands |
| `<leader>sr` | Search and replace |

## Buffers

| Key | Action |
|---|---|
| `<leader>fb` | Switch buffer |
| `<leader>bd` | Delete buffer |
| `<leader>bD` | Delete buffer (force) |
| `<leader>bn` | Next buffer |
| `<leader>bp` | Previous buffer |
| `<leader>bq` | Close all buffers but this |

## Windows

| Key | Action |
|---|---|
| `<leader>wv` | Vertical split |
| `<leader>wh` | Horizontal split |
| `<leader>wc` | Close window |
| `<leader>wo` | Close other windows |
| `Ctrl+h/j/k/l` | Move between windows |
| `Ctrl+arrows` | Resize windows |

## Terminal

| Key | Action |
|---|---|
| `<leader>tt` | Terminal (horizontal) |
| `<leader>tT` | Terminal (float) |
| `<leader>tv` | Terminal (vertical) |
| `<leader>1` | Run shell command |
| `Ctrl+t` | Exit terminal mode |

## Diagnostics

| Key | Action |
|---|---|
| `<leader>xx` | Diagnostics buffer |
| `<leader>xw` | Document diagnostics |
| `<leader>xq` | Quickfix list |
| `<leader>xl` | Location list |
| `<leader>q` | Diagnostic quickfix (built-in) |
| `<leader>td` | Toggle diagnostics on/off |

## Compile

| Key | Action |
|---|---|
| `<leader>cc` | Compile |
| `<leader>cr` | Recompile |
| `<leader>cq` | Close compile window |

## Directory

| Key | Action |
|---|---|
| `<leader>cd` | Cd to current file directory |
| `<leader>cD` | Cd to project root |

## Session

| Key | Action |
|---|---|
| `<leader>ss` | Save session |
| `<leader>sl` | Restore session |
| `<leader>sd` | Delete session |
| `<leader>s.` | Search sessions |

## LSP

| Key | Action |
|---|---|
| `grd` | Go to definition |
| `grD` | Go to declaration |
| `grt` | Go to type definition |
| `gri` | Find implementations |
| `grr` | Find references |
| `grn` | Rename |
| `gra` | Code action |
| `gO` | Document symbols |
| `gW` | Workspace symbols |
| `K` | Hover |
| `<leader>ca` | Code action |
| `<leader>th` | Toggle inlay hints |

## Other

| Key | Action |
|---|---|
| `<leader>u` | Undo tree |
| `<leader>sh` | Help for word under cursor |
| `<Esc>` | Clear search highlight |
